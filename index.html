Playing

  • Click a channel — tune in
  • Click again — stop
  • ★ — add/remove from favourites
  • Volume slider — bottom bar, desktop only

Navigating

  • Preset rail — filter by network (ALL, SF, RB, YLE)
  • ★ FAVES — your saved stations
  • Search bar — filter channels by name in the current view

Custom stations

  • + BROWSE — search radio-browser.info by name or tag
  • + add — saves a station to your personal list
  • my pick badge — marks stations you added
  • ✕ — removes a custom station

Networks

SF — SomaFM
RB — Radio Browser curated + your picks
YLE — Finnish public radio

About

Signal is a static page — no server, no account. Favourites and stations you add live only in this browser (localStorage), so they won't follow you to another device or show up for anyone else using this same page.
